# Data

The analysed FCS files are not versioned in this repository
(file size + ethics). They are available at the following Zenodo DOI:
https://doi.org/10.5281/zenodo.22893790

Expected input format: a concatenated FCS file containing `FileID` (sample)
and `FolderID` (condition) columns, with `File<N>_Name` and `Folder<N>_Name`
metadata keywords.
